# Feature Specification: 平板智慧家居儀表板 UI／UX

**Feature Branch**: `003-tablet-smart-home-ui`
**Created**: 2026-08-19
**Status**: Ready for implementation
**Language**: zh-TW

## User Scenarios & Testing

### User Story 1 - 在平板上舒適地使用收納寶盒（Priority: P1）

使用者以 768px 以上的平板開啟 App 時，希望看到真正利用平板空間的控制台，而不是被限制在手機寬度的畫面；使用者在手機上則維持熟悉的底部導覽。

**Independent Test**: 在 375×812、768×1024 與 1024×768 三種尺寸開啟首頁與其他主頁，平板出現左側主導覽、內容最大寬度為 1024px，手機出現底部導覽，且所有內容均可垂直瀏覽、沒有水平捲動。

**Acceptance Scenarios**:

1. **Given** 使用者以 768px 以上寬度開啟 App，**When** 進入任一主頁，**Then** 左側顯示包含圖示與文字的主導覽，右側顯示頁首與內容。
2. **Given** 使用者以小於 768px 寬度開啟 App，**When** 進入任一主頁，**Then** 維持底部五項導覽，內容不被固定導覽遮住。
3. **Given** 使用者使用寬度大於 1024px 的視窗，**When** 開啟 App，**Then** App 殼層置中且內容不無限制拉寬。
4. **Given** 使用者在平板橫向瀏覽，**When** 捲動各主頁，**Then** 表單保持可讀寬度，清單與儀表板可使用雙欄空間。

### User Story 2 - 從首頁快速掌握家庭庫存（Priority: P1）

使用者打開首頁時，希望立即知道目前家庭、物品數、位置數與同步狀態，也能用大型快捷控制直接新增物品、搜尋物品或查閱位置。

**Independent Test**: 在有本機物品與位置的家庭中開啟首頁，確認三個摘要數字、三個快捷控制與最近物品清單正確；空資料時顯示可執行的第一件物品入口。

**Acceptance Scenarios**:

1. **Given** 家庭有未刪除物品與位置，**When** 使用者開啟首頁，**Then** 顯示物品總數、位置總數與待同步數量。
2. **Given** 使用者在首頁，**When** 點擊「新增物品」、「搜尋物品」或「查閱位置」快捷控制，**Then** 進入對應既有頁面。
3. **Given** 家庭沒有本機物品，**When** 首頁載入完成，**Then** 顯示說明空狀態與「新增第一件物品」入口。
4. **Given** 家庭有最近物品，**When** 使用者查看首頁，**Then** 每張卡片顯示名稱、分類與可辨識的位置資訊；平板以雙欄呈現。
5. **Given** App 處於純離線模式，**When** 使用者查看首頁，**Then** 同步區塊如實顯示純離線狀態，不製造錯誤提示。

### User Story 3 - 以一致且易按的控制完成操作（Priority: P2）

使用者在登入、表單、照片、設定、位置與確認視窗中，希望每個控制都有一致的大小、層級、按壓回饋與狀態，不需要精準點擊小圖示。

**Independent Test**: 逐頁檢查主要、次要、危險、圖示與載入中控制，確認每個可操作區域至少 44–48px，鍵盤與螢幕閱讀器可辨識，操作後有清楚狀態回饋。

**Acceptance Scenarios**:

1. **Given** 使用者看到主要操作，**When** 點擊或以鍵盤聚焦，**Then** 控制有明確的 pressed/focus 狀態且不造成周邊版面跳動。
2. **Given** 操作正在處理，**When** 使用者再次點擊，**Then** 控制暫時停用並顯示載入文字或進度。
3. **Given** 使用者看到圖示按鈕，**When** 使用螢幕閱讀器，**Then** 可讀取描述性的操作名稱。
4. **Given** 使用者執行危險操作，**When** 顯示確認視窗，**Then** 取消與確認的順序、色彩與安全邊距清楚一致。

### User Story 4 - 在各功能頁維持平板閱讀節奏（Priority: P2）

使用者在新增、搜尋、位置、設定、物品詳情與位置詳情頁操作時，希望資訊依相關性分組，平板能使用多欄，但文字、照片與階層內容仍容易閱讀。

**Independent Test**: 逐一開啟所有既有路由，在平板與手機尺寸確認沒有被壓窄的表單、被遮住的固定元素、水平捲動或破壞既有路由的操作。

**Acceptance Scenarios**:

1. **Given** 使用者在新增物品頁，**When** 使用平板輸入資料，**Then** 相關欄位分組排列，主要儲存操作保持醒目且易按。
2. **Given** 使用者在搜尋頁，**When** 使用平板查看結果，**Then** 篩選可辨識，結果卡片以雙欄呈現且可正常進入詳情。
3. **Given** 使用者在設定頁，**When** 查看多個設定區塊，**Then** 區塊以響應式卡片排列，家庭與成員區塊保留足夠寬度。
4. **Given** 使用者在物品或位置詳情，**When** 查看照片、操作與歷史，**Then** 資訊層級與返回、編輯、刪除等既有行為維持不變。

### User Story 5 - 在不同裝置與輔助設定下仍可操作（Priority: P3）

使用者可能使用鍵盤、螢幕閱讀器、放大文字或減少動態效果，希望介面仍保持可理解與可操作。

**Independent Test**: 以鍵盤走過主導覽、首頁快捷控制、表單與彈窗，開啟 reduced motion 並檢查文字對比與動態內容公告。

**Acceptance Scenarios**:

1. **Given** 使用者以鍵盤操作，**When** 逐項 Tab，**Then** focus 順序符合視覺順序且焦點清楚可見。
2. **Given** 使用者啟用 prefers-reduced-motion，**When** 切換頁面或按壓控制，**Then** 不出現造成干擾的動態效果。
3. **Given** 使用者放大文字，**When** 查看首頁、表單與設定，**Then** 文字不被截斷，控制仍可操作。
4. **Given** 使用者遇到錯誤或成功結果，**When** 狀態更新，**Then** 除了顏色外也有文字或圖示說明。

## Functional Requirements

- **FR-001**: App MUST 在 768px 以上顯示左側主導覽，在 768px 以下顯示既有手機底部導覽。
- **FR-002**: App shell MUST 在平板以上維持 1024px 最大寬度並置中，且不得產生水平捲動。
- **FR-003**: 首頁 MUST 顯示家庭名稱、物品總數、位置總數、同步摘要與最近物品。
- **FR-004**: 首頁 MUST 提供新增物品、搜尋物品、查閱位置三個快捷控制，並導向既有路由。
- **FR-005**: 空首頁 MUST 提供新增第一件物品的可操作入口。
- **FR-006**: 所有新增或修改的主要控制 MUST 使用一致的 primary、secondary、ghost、danger 層級。
- **FR-007**: 所有圖示單獨作為控制時 MUST 有描述性的 aria-label，點擊區域 MUST 至少 44px，主要平板控制以 48px 為目標。
- **FR-008**: 控制 MUST 支援 pressed、focus-visible、disabled 與 loading 狀態，且不依賴 hover 才能完成操作。
- **FR-009**: 表單、清單、設定、詳情、照片與彈窗 MUST 在手機及平板保持可讀、可捲動與安全邊距。
- **FR-010**: 既有路由、離線優先資料流、同步狀態、權限規則與後端合約 MUST 維持不變。
- **FR-011**: 介面 MUST 使用語意化色彩與文字／圖示雙重回饋，並在 light theme 達到 WCAG AA 可讀性。
- **FR-012**: 動畫 MUST 支援 prefers-reduced-motion，微互動時間控制在約 150–220ms，且不得造成內容位移。

## Key Entities

本功能不新增持久化實體。首頁摘要使用既有物品、位置與執行期同步狀態；按鈕元件與導覽配置均為前端執行期介面。

## Success Criteria

- **SC-001**: 在 768×1024 與 1024×768 視窗，使用者可看到左側主導覽與不超過 1024px 的置中內容，頁面沒有水平捲動。
- **SC-002**: 使用者從首頁到新增、搜尋或位置頁最多一次點擊即可完成入口導向。
- **SC-003**: 首頁摘要數字與本機未刪除資料一致；空資料時新增第一件物品入口可見且可操作。
- **SC-004**: 100% 的可見互動控制具有鍵盤 focus、disabled/pressed 回饋與至少 44px 觸控區域；圖示按鈕具有可讀名稱。
- **SC-005**: 手機既有路由與離線操作回歸測試保持通過，且平板專用導覽不改變路由 URL 或資料行為。
- **SC-006**: 在 reduced-motion 與放大文字情境下，主頁與表單仍能完成導覽與儲存，不出現內容被截斷或遮蔽。

## Assumptions

- 本批只改版面、元件、狀態回饋與首頁摘要，不新增真正的智慧家居裝置控制資料。
- 平板主導覽使用左側 navigation rail；手機保留底部導覽。
- 以既有系統字型與離線優先原則為準，不新增外部字型或 UI 套件。
- 平板最大內容寬度固定為 1024px；更大視窗只增加外圍留白。
